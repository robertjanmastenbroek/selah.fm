# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Selah.fm, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, send an email to **security@selah.fm** with:

- A clear description of the vulnerability
- Steps to reproduce
- The affected component or endpoint
- Any potential impact

### What to Expect

1. **Acknowledgment**: You'll receive a response within 48 hours confirming receipt.
2. **Investigation**: We'll investigate and determine the severity and scope.
3. **Fix**: We'll develop and test a fix. Critical vulnerabilities are patched within 72 hours.
4. **Disclosure**: After the fix is deployed, we'll publish a security advisory and credit you (unless you prefer to remain anonymous).

### Supported Versions

| Version | Supported |
|---------|-----------|
| Latest `main` branch | ✅ |
| Older versions | ❌ |

### Scope

The security policy covers:
- The Selah.fm web application (https://selah.fm)
- API endpoints
- Authentication and session management
- Payment processing (Stripe integration)
- Data handling and storage

### Out of Scope

- Issues requiring physical access to a user's device
- Social engineering attacks
- Denial of service attacks
- Issues in third-party services (Stripe, Neon, Railway)

Thank you for helping keep Selah.fm secure.
