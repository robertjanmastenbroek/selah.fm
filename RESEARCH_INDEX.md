## Research Protocol (For All Future Work)

1. **CHECK FIRST** — Before any research, consult this index. If a document exists, READ IT.
2. **CITE SOURCES** — When referencing existing research, cite the document name and key finding.
3. **NO DUPLICATION** — If a finding exists in any .md file, reference it — don't re-derive it.
4. **KEEP CURRENT** — When implementing something that was previously researched, update the research doc with "✅ BUILT" status.
5. **ADD NEW FINDINGS** — When you discover something new during implementation that isn't in any .md, add it to the relevant document or create a new one.
6. **INDEX UPDATES** — After adding/updating research, update this index document.
